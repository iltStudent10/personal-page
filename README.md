# Personal Page

A minimal personal portfolio used to demonstrate Git and the Github workflow.

This repository contains a simple static site, documentation, and an EXPLANATION.md describing branching and commit philosophy.

## Quick Start
1. Clone:
    ```bash
    git clone https://github.com/iltStudent10/personal-page.git
    ```
2. Open index.html in a browser to view the site,

## View Locally
Open index.html in your browser or serve with a simple static server (python -m http.server). Consider enabling Github Pages for a live URL.

## Repository Structure
1. index.html - Landing Page
2. assets/css/styles.css - basic styling
3. EXPLANATION.md - branching strategy, commit philosophy, and production improvements
4. .gitignore - ignored files
5. LICENSE - MIT license

## Contributing
1. Use short-lived feature branches (deature/, fix/, chore/)
2. Commit messages should be imperative, and explain what and why
3. Create PRs with clear title and description; keep PRs focused
